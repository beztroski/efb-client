# Escape From Brilsk

## О проекте

Escape From Brilsk — это ГЛУБОКАЯ хардкорная модификация на базе Minecraft, Здесь нет казуала и донатов. 
У нас продуманная система здоровья, реалистичное оружие, мрачная атмосфера, хороший саунд дизайн, и уникальная история БНСР

## Как начать играть

1. Откройте Telegram бота [@efb_id_bot](https://t.me/efb_id_bot) и пройдите капчу
2. Зарегестрируйте свой аккаунт и нажмите "Нет клиента?"
3. Бот автоматически отправит вам свежий установщик, больше устанавливать вам его не нужно будет, лаунчер будет обновляться автоматически

## Для чего нужен этот репозиторий

Здесь хранятся файлы, необходимые для работы лаунчера сборки. Лаунчер автоматически обращается к этому репозиторию для загрузки и обновления компонентов.
